# PoleWatch 디자인 핸드오프 (다크 테마)

사무실에서 쓰는 데스크톱 대시보드(1280~1440px)입니다. 기능 범위와 우선순위는 `PoleWatch_앱_기능명세서.md`를 따릅니다.
Claude Code에서 작업한다면 이 문서와 `tokens.css`를 먼저 읽히고, 화면별 마크업은 `artboards/`에서 참고하세요.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| `DESIGN.md` | 이 문서. 색·타입·컴포넌트·동작 규칙 |
| `tokens.css` | CSS 변수로 정리한 디자인 토큰 (다크 테마) |
| `artboards/Main.dc.html` | 화면 A. 지도·목록 (1440×900) |
| `artboards/Detail.dc.html` | 화면 B. 전주 상세·검수 (1440×1120) |
| `artboards/Device.dc.html` | 화면 C. 기기 상태 (1440×900) |
| `artboards/States.dc.html` | 빈 상태·필터 결과 없음·위치 없음·동기화 3상태 (1440×660) |
| `artboards/canvas.json` | 디자인 캔버스의 보드 배치 정보 (구현에는 불필요) |

### `.dc.html` 파일 읽는 법
- 디자인 캔버스 전용 포맷이라 브라우저에서 바로 열면 렌더링되지 않습니다 (`support.js` 런타임 필요). **구현용 참고 소스**로 쓰세요.
- 스타일은 전부 인라인 `style="…"`에 있어 수치를 그대로 옮길 수 있습니다.
- `{{name}}`은 템플릿 값, `<sc-for>`는 반복, `<sc-if>`는 조건부 렌더링입니다.
- 파일 맨 아래 `<script type="text/x-dc">`의 `renderVals()`에 샘플 데이터, 선택·필터 상태, 파생 스타일 계산이 있습니다. 상태 로직은 여기를 보면 됩니다.
- 전주 ID, 좌표, 시간, 기기 수치는 모두 **예시 데이터**입니다.

## 색

바탕은 검정 계열이고 강조색은 노랑 하나입니다. 빨강은 "위험"에만 씁니다. 그 밖에 새 색상(hue)은 추가하지 않습니다.

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 상단 바 | `#0A0A0A` + 하단 1px `#262626` | 공통 상단 바 |
| 페이지 바탕 | `#111111` | 화면 배경, 카드 안의 오목한 영역(세그먼트 필터 바탕, 안내 박스) |
| 카드/패널 | `#1C1C1C` + `0 0 0 1px #2E2E2E` | 목록 패널, 상세 카드 |
| 올라온 면 | `#333333` | 선택된 세그먼트 버튼 |
| 본문 텍스트 | `#EDEDEA` | |
| 보조 텍스트 | `#A3A3A0` | 라벨, 캡션, 축 |
| 비활성 | `#6A6A6A` | 비활성 버튼 아이콘 |
| 브랜드 | `#FFD21F` | 로고, 현재 탭 밑줄, 주행 경로, 선택 링, 주요 버튼, 현재 처리 단계, 검출 박스 |
| 브랜드 틴트 | `#2B2616` | 선택된 목록 행 배경 (링은 `#FFD21F` 2px inset) |
| 위험 | 채움 `#E5483D`, 선 `#FF6B5E`, 글자 `#FF8A80`, 틴트 `#3A1614` | 위험 등급, 경고 기준선, GPS 미수신 |

노란색 위의 글자와 아이콘은 항상 `#141414`를 씁니다.

## 위험 등급 표시 (색만으로 구분하지 않음)

| 등급 | 모양 | 채움 | 글자 |
|---|---|---|---|
| 위험 | 45° 회전 사각형(마름모) 22px, 모서리 3px | `#E5483D` | "위" `#141414` 12px 700 (글자는 -45° 되돌림) |
| 주의 | 원 26px | `#EDEDEA` | "주" `#141414` |
| 양호 | 원 24px, 2px 테두리 `#9A9A96` | `#1C1C1C` | "양" `#9A9A96` |

- 지도 마커는 44×44 투명 버튼 가운데에 위 글리프를 둡니다. 평소에는 `0 0 0 2px #111111` 링을 두르고, 선택하면 `scale(1.4)`에 `0 0 0 3px #FFD21F, 0 0 0 5.5px #EDEDEA` 링을 둡니다.
- 범례, KPI, 목록 행, 상세 배지 모두 같은 글리프를 씁니다.

## 처리 상태 필

| 상태 | 스타일 |
|---|---|
| 신규 | 배경 `#EDEDEA`, 글자 `#141414` |
| 확인 | 배경 `#2E2E2E`, 글자 `#EDEDEA` |
| 철거 예정 | 투명 배경, `inset 0 0 0 1.5px #EDEDEA` |
| 철거 완료 | 투명 배경, 글자 `#A3A3A0`, `inset 0 0 0 1.5px #4A4A4A` |
| 해당 없음(양호) | 글자 `#A3A3A0`만 |

필 공통: 패딩 3px 8px, 모서리 4px, 12px 600.

## 타이포그래피

- 본문: **IBM Plex Sans KR** (400/500/600/700)
- 숫자 식별자(전주 ID, 좌표, 시각, 퍼센트): **IBM Plex Mono** (400/500)
- 숫자 집계에는 `font-variant-numeric: tabular-nums`

| 상세 전주 ID | 24px Mono 500 |
| 패널 제목 | 17px 700 |
| 카드 제목 | 15px 700 |
| 본문 | 14px |
| 보조 | 13px |
| 캡션/필 | 12px |
| 차트 축 | 11px |

## 치수 규칙

- 클릭 대상은 최소 44px (버튼, 셀렉트, 마커, 목록 행 최소 64px)
- 모서리: 카드 12, 떠 있는 요소(요약 카드·범례·줌) 10, 컨트롤 8, 썸네일 6, 필 4
- 형제 요소 간격은 flex/grid `gap`으로 (8, 12, 16, 24)
- 화면 여백 24px, 카드 사이 16px

## 화면별 구성

### 공통 상단 바 (64px)
로고(노란 사각형 30px + 검정 전주 도형) · 탭 3개(현재 탭은 흰 글자 + 노란 3px 밑줄) · 우측에 동기화 상태.
동기화 상태는 3가지입니다 (`States.dc.html`).
- 완료: 노란 원 체크 + "동기화 완료" + 마지막 동기화 시각(Mono)
- 진행 중: 노란 호 스피너 + 이미지 n / N + 72px 진행 막대
- 실패: 빨간 삼각 경고 + 원인 + "다시 시도" 버튼

### A. 지도·목록 (`Main.dc.html`)
- KPI 줄(88px): 기준 날짜 버튼 | 기록 전주 · 위험 · 주의 · 양호 수. 오탐 판정은 집계에서 뺍니다.
- 지도(나머지 폭): 주행 경로는 노랑 6px에 `#050505` 11px 테두리. 미점검 도로는 `#5F6368` 3px 점선(7/6). 출발·종료 핀과 라벨이 있습니다.
- 지도 위 떠 있는 요소
  - 오른쪽 위: 선택한 전주 요약 카드(360px). 썸네일 136×102, 좌표, 위험 유형, 기록 시각, 처리 상태, [상세 보기(노랑)] [확인 처리(토글)]
  - 왼쪽 아래: 범례
  - 오른쪽 아래: 확대/축소
- 목록(440px): 제목 + 건수 + CSV 내보내기 / 등급 세그먼트(전체·위험·주의·양호, 건수 포함) / 위험 유형·처리 상태·정렬 셀렉트 / 스크롤되는 행 목록
- 연동: 마커 클릭과 행 클릭은 같은 선택 상태를 씁니다. 등급 필터는 지도와 목록에 함께 적용합니다.
- 좌표 없는 기록은 지도에 그리지 않습니다. 목록에만 "위치 없음" 표시(핀에 사선 아이콘)와 "ID 미할당"으로 나옵니다.

### B. 전주 상세·검수 (`Detail.dc.html`)
- 서브 헤더(76px): ← 지도·목록 | 전주 ID | 등급 배지 | 위험 유형 태그 | (오탐이면 "오탐 · 집계 제외") | 위험 전주 n / N, 이전·다음
- 왼쪽 크롭 뷰어(888px)
  - 툴바: 크롭 n / N, 검출 박스 스위치, 확대/축소(100·150·200·300%)
  - 본 이미지 856×642 (4:3)
  - 썸네일 5칸: 실제 개수만큼 채우고 남은 칸은 "크롭 없음"
- 검출 박스
  - 까치집: 노랑 3.5px 박스 + 노란 라벨(검정 글자)
  - 전주: 흰 점선 박스 + 흰 라벨
- 오른쪽 카드 4개
  - 기록 정보: 좌표 · 시각 · 유형 · 진행 방향 + 등급 근거 3단 게이지
  - 판정 검수: 맞음 / 오탐. 누른 쪽은 밝은 면으로 반전됩니다. 오탐이면 재학습 폴더 저장 안내가 나오고, 선택 취소도 가능합니다.
  - 처리 상태: 신규 → 확인 → 철거 예정 → 철거 완료. 단계를 눌러 바꾸고 되돌리기 가능. 현재 단계는 노란 원, 지난 단계는 체크.
  - 이력 비교: 이전 방문 / 오늘 썸네일과 둥지 크기 등급 변화

### C. 기기 상태 (`Device.dc.html`)
- 주행 기록 선택 버튼, KPI 타일 4개(최고 온도, 평균 전력, 프레임 드롭 합계, GPS 수신율)
- 차트 3개: 온도(선, 경고 기준 점선), 전력(선), 프레임 드롭(분당 막대)
  - 한 차트에 시리즈 하나만, 선 2px `#EDEDEA`, 축은 연하게
  - 마우스를 올리면 세로 가이드선, 노란 점, 밝은 툴팁(시각 + 값)
- GPS 수신 띠: 분 단위 22칸. 수신은 밝은 칸, 미수신은 빨간 테두리 + 빗금. 아래에 미수신 구간이 목록의 "위치 없음" 기록과 연결된다는 안내를 둡니다.

## 지도 구현 메모
- 명세대로 Folium/Leaflet을 쓰면 API 키가 필요 없습니다. 디자인의 지도 배경은 타일이 들어갈 자리를 대신 그린 것입니다.
- 어두운 계열 타일을 고르면 이 톤에 맞습니다. 타일 제공처의 이용 조건(트래픽, 출처 표기)은 따로 확인하세요.
- 경로, 미점검 도로, 마커는 타일 위 벡터 레이어로 그리고 색은 위 토큰을 씁니다.

## 미정 사항 (명세서 10장과 연결)
- 등급 판정 기준: 상세 화면의 "까치집 크기 등급 소/중/대" 게이지는 자리만 잡아 둔 예시입니다.
- 전주 ID 규칙: GPS 미수신 기록의 ID를 어떻게 줄지 정해야 합니다(현재 "ID 미할당" 표기).
- 이력 비교 포함 여부, 수목 클래스 확보 여부.
